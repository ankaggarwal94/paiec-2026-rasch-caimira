# Release audit

## Exact target and decision

The target is the original 55,644-byte `18-s44-rasch-caimira.zip` for Codabench 1033935, together with the author's latest report commit `8a156a203deb0fe3b2ab3e9e333803feb61c9501`. This revision preserves the submitted candidate and the latest author and diagram edits. It improves source disclosure, execution evidence, and reviewer reproducibility.

The release is ready as a local reviewed package. Publication and several historical data-reconstruction requirements remain explicit completion steps in `COMPLIANCE.md`.
